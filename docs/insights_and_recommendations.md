# Insights and Recommendations

## Supported Insights

1. Average user activity suggests a moderate activity baseline.

   The processed dataset shows an average of 7,652 daily steps and 2,308 daily calories. This supports engagement messaging around consistent daily movement rather than only high-intensity activity.

2. Activity varies by day of week.

   The current weekday output shows Saturday with the highest average steps and Sunday with the lowest average steps. Sunday also has the highest average sleep duration in the current output.

3. Weekend sleep duration is higher than weekday sleep duration.

   The weekday vs weekend output shows 7.27 average sleep hours on weekends compared with 6.89 on weekdays.

4. Steps and calories have a moderate positive relationship.

   The current correlation output shows a 0.412 correlation between total steps and calories. This supports activity-based challenges, but it should not be presented as a causal relationship.

## Business Recommendations

1. Use activity-based segments for targeted marketing.

   Bellabeat could tailor campaigns for low, moderate, and highly active users once segmentation thresholds are confirmed. This would make messaging more relevant than a single generic campaign.

2. Promote goal-setting features to support daily engagement.

   Since steps and calories move together in the current output, campaigns could encourage achievable step goals, streaks, and progress tracking.

3. Use weekend-specific wellness messaging.

   Current outputs suggest different weekday and weekend patterns. Bellabeat could test Saturday activity challenges and Sunday recovery or sleep-focused reminders.

4. Build recovery-focused messaging around sleep and activity routines.

   Sleep records are available for a smaller subset of users, but the available data can still support cautious wellness messaging about routine, rest, and balance.

5. Improve insight confidence with additional business data.

   Adding app engagement, customer profile, subscription, or campaign data would make recommendations more commercially actionable.
