# Analysis Methodology

1. Understand the business question

   Bellabeat wants to understand smart device usage patterns and identify practical opportunities for marketing, user engagement, and wellness product decisions.

2. Inspect dataset structure

   Review available raw and processed files, including daily activity, steps, calories, active minutes, sleep records, user IDs, and dates.

3. Clean and prepare data

   Standardise date fields, check data types, review duplicates and null values, and prepare a combined daily activity and sleep table for analysis.

4. Explore user activity patterns

   Analyse average steps, calories, active minutes, and sedentary minutes to understand daily engagement.

5. Explore sleep or wellness behaviour if available

   Use matched sleep records to compare sleep duration and sleep-related fields across dates and day types.

6. Segment users if supported

   Create optional activity-level segments once business rules are confirmed. Example segments could classify users by average daily steps, but thresholds must be documented before use.

7. Translate findings into business recommendations

   Convert supported patterns into practical recommendations for targeted marketing, goal-setting features, recovery-focused messaging, and personalised engagement.
