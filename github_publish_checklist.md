# GitHub Publish Checklist

- [ ] Check no private information is included.
- [ ] Check no local file paths are included.
- [ ] Check no credentials, API keys, or tokens are included.
- [ ] Check dataset source and licence are mentioned.
- [ ] Check README links work.
- [ ] Check dashboard screenshots are added to `assets/screenshots`.
- [ ] Check SQL files are readable and have business-question comments.
- [ ] Check insights do not include unsupported numbers.
- [ ] Check limitations are included.
- [ ] Check repository description is updated.
- [ ] Check duplicated raw data folders are intentional before publishing.
- [ ] Check large raw data files comply with GitHub and dataset licence expectations.
